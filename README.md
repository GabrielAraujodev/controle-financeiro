# Controle Financeiro 💰

Um aplicativo web simples e eficiente para controle de despesas e receitas mensais.

🔗 **Demo:** [https://gabrielaraujodev.github.io/controle-financeiro/](https://gabrielaraujodev.github.io/controle-financeiro/)

## 📋 Funcionalidades

- ✅ Adicionar transações (receitas e despesas)
- ✅ Visualizar saldo atual
- ✅ Acompanhar total de receitas e despesas
- ✅ Histórico de transações
- ✅ Remover transações
- ✅ Armazenamento local (localStorage) - seus dados persistem mesmo após fechar o navegador
- ✅ Design responsivo para dispositivos móveis

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura da página
- **CSS3** - Estilização e layout responsivo
- **JavaScript (Vanilla)** - Lógica da aplicação
- **LocalStorage API** - Persistência de dados no navegador

## 💻 Como Usar

1. **Clone ou baixe este repositório**
   ```bash
   git clone https://github.com/gabrielaraujodev/controle-financeiro.git
   ```

2. **Abra o arquivo `index.html`** em seu navegador:
   - Basta dar um duplo clique no arquivo `index.html`, ou
   - Use uma extensão como "Live Server" no VS Code

3. **Adicione transações:**
   - Preencha o nome da transação
   - Insira o valor (use números positivos para receitas e negativos para despesas)
   - Clique em "Adicionar"

4. **Gerencie suas transações:**
   - Passe o mouse sobre uma transação para ver o botão de excluir
   - Clique no "X" para remover uma transação
